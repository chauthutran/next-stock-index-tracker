# The file public/data/stock-data.json has stock data for five stocks and a year of simulated daily prices.
This is demo data, not live market data. The default market lists use index symbols
that are not currently included in this file, so those lists remain empty until
matching index data is added.

Symbols	Company	Data included
AAPL	Apple	Quote + daily history
MSFT	Microsoft	Quote + daily history
NVDA	NVIDIA	Quote + daily history
AMZN	Amazon	Quote + daily history
GOOGL	Alphabet	Quote + daily history
